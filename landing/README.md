# Лендинг Симп

Статический сайт без сборки: чистый HTML, CSS и ванильный JS. Нет
зависимостей, нет тулчейна — разворачивается копированием папки.

## Состав

| Файл | Назначение |
|---|---|
| `index.html` | Главная: hero с CSS-макетом телефона, шаги, bento-сетка возможностей, безопасность, FAQ, CTA |
| `privacy.html` | Политика конфиденциальности |
| `terms.html` | Условия использования (18+, платные функции, ответственность) |
| `guidelines.html` | Правила сообщества |
| `moderation.html` | Политика модерации контента |
| `support.html` | Поддержка и частые вопросы |
| `styles.css` | Общие стили на токенах дизайн-системы приложения |
| `app.js` | Scroll-reveal, мобильное меню, плавный скролл, год в подвале |
| `icon.svg`, `og-image.png` | Логотип и превью для соцсетей |
| `robots.txt`, `sitemap.xml` | SEO |

Все четыре юридических документа обязательны для публикации
dating-приложения в App Store: ссылки на них указываются в App Store
Connect и продублированы в приложении (Профиль → документы).

## Локальный просмотр

```bash
cd landing
python3 -m http.server 8000
# http://localhost:8000
```

## Деплой

**Cloudflare Pages** (рекомендуется — бесплатно, CDN, автоматический HTTPS):

```bash
npx wrangler pages deploy landing --project-name simp
```

**Railway / любой статический хостинг:** отдавайте папку `landing`
как корень сайта. Сборка не нужна.

**Nginx:**

```nginx
server {
    server_name simp.app;
    root /var/www/simp/landing;
    index index.html;
    location / { try_files $uri $uri/ =404; }
}
```

## Что заменить перед публикацией

Значения-заглушки, которые нужно обновить на реальные:

1. **Ссылка на бота** — `https://t.me/simpmatchbot` встречается во всех
   HTML-файлах. Замените на реальное имя бота:
   ```bash
   cd landing
   sed -i '' 's|t.me/simpmatchbot|t.me/ВАШ_БОТ|g' *.html
   ```
2. **Домен** — `https://simp.app` в `canonical`, Open Graph,
   `sitemap.xml` и `robots.txt`.
3. **Адреса почты** — `support@`, `privacy@`, `safety@simp.app`
   должны существовать и приниматься.
4. **Ссылка в App Store** — на главной кнопка «Скачать в App Store»
   ведёт на секцию `#ios`. После публикации приложения замените на
   реальный адрес в App Store.
5. **Юридические реквизиты оператора** — единственная заглушка, которую
   нельзя заполнить из репозитория: организация не зарегистрирована.
   Текст об операторе — один блок между маркерами `ОПЕРАТОР:НАЧАЛО` и
   `ОПЕРАТОР:КОНЕЦ`, вставленный посимвольно одинаково в `terms.html` и
   `privacy.html`. Заполнять так:

   ```
   1. впишите наименование, ОГРН/ИНН и адрес в блок — в обоих файлах;
   2. удалите абзац с data-legal-pending="operator-entity" — тоже в обоих;
   3. удалите этот пункт из README;
   4. npm run sync:landing && pytest api/tests/test_legal_operator.py
   ```

   Правьте только `landing/` — `web/public` производная, её пересобирает
   `npm run sync:landing`. Пока заглушка стоит, §12 условий применяет право
   страны постоянного проживания человека: отсылка к юрисдикции
   неназванного оператора не означала бы ничего. Все инварианты держит
   `api/tests/test_legal_operator.py` — он же не даст снять плашку, ничего
   не подставив.

## Проверка перед публикацией

```bash
# Битые внутренние ссылки и валидность разметки
cd landing && python3 -m http.server 8000 &
curl -s -o /dev/null -w "%{http_code}\n" http://localhost:8000/privacy.html
```

Страницы проверены: разметка сбалансирована, внутренних битых ссылок
нет, все ресурсы отдаются. Визуальное оформление наследует токены
`web/src/styles/globals.css`, поэтому лендинг и приложение выглядят
одним продуктом.
